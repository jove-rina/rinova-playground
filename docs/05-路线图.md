# 05 路线图

## 原则

1. **每个里程碑可独立验收**，验收不通过不进下一个
2. **v0.1 全部重新实现**：不迁移、不复制任何既有项目代码；旧项目的经验只作为需求输入
3. **先内部跑通，再对外开源**：没有 dogfood 结果不发 v0.1
4. 每个里程碑结束产出可运行的东西，不允许"只写了架构没有页面"

## 里程碑

| M | 周期 | 内容 | 验收 |
|---|---|---|---|
| **M0** 内核骨架 | 1 周 | Vue3 外壳（侧栏 + 预览 + 工具栏）、场景扫描与虚拟模块、自研原语首批（Button/Input/Toast/Portal/FocusTrap）、12 个主题变量、静态 shiki 代码块 | 一个三场景的最小项目 `pnpm dev` 可跑；侧栏结构与目录一致；`pnpm build` 产出纯静态站点 |
| **M1** 文件路由 + 脚手架 | 1 周 | history 路由、场景切换与销毁、`sceneMeta` 构建期解析、`create-rinova-playground` 脚手架、运行时包 dist 构建 | 空 Vue3 项目 3 分钟内出 5 个场景；命令数 ≤ 3 |
| **M2** 代码展示层 | 1.5 周 | ✅ Monaco 0.57 + `@shikijs/monaco` 懒加载只读查看、多文件 Tab（场景 + `sceneMeta.files`）、失败降级、入参/出参面板（`useScenePayload`） | ✅ 首屏 monaco 请求数 = 0；token 取色与静态块一致；降级不报错；出参随交互 400ms 内更新 |
| **M3** 契约清单 | 1 周 | ✅ `vue-component-meta` 提取、`.playground/manifest.json` + `llms.txt` + `coverage.md`、props 覆盖报告、dev 下组件变更自动重算 | ✅ 覆盖率报告指出被故意留空的 `loading`（5/6）；manifest 字段与源码一致 |
| **M4** 文档站 + 发布 | 1 周 | ✅ 文档站 `examples/docs-site`（用自己搭自己，8 个场景）、`examples/minimal-lib`、三包版本 0.1.0 + `npm pack` 校验；剩余：`examples/real-lib`、找 2 位未参与者验收、npm 登录后正式发布 | 首屏 JS ≤ 300KB（不含编辑器）：实测 30.2KB gz；文档站能完整介绍框架 |
| **M5** AI 能力 | 2 周 | ✅ `@rinova/playground-mcp`：`capability_search` / `capability_get` / `scenario_list` / `coverage_report`（stdio、只读）；`try` / `author` 明确不做 | ✅ 冒烟 7/7：握手、工具面、契约含行号锚点、覆盖报告、未知组件报错 |

## 阶段产物与发布点

| 发布 | 内容 | 前置 |
|---|---|---|
| `v0.1.0`（M4 后） | 框架可用：文件即场景 + Monaco 代码层 + 契约清单 + 文档站 | M0–M4 全绿 |
| `v0.2.0` | 编辑模式开放、diff 视图、出参差异高亮、payload 交互 | 有真实使用者反馈 |
| `v0.3.0` | MCP + AI 生成场景闭环 | M5 |

## 每个里程碑的固定检查项

- [ ] `pnpm build` 通过，产物体积记录在案（首屏 / 编辑器 chunk 分开记）
- [ ] 无 `@/` 之类的项目内绝对别名引用（内核只允许相对路径与包名）
- [ ] 无 UI 库依赖（`grep -r "element-plus\|naive-ui\|ant-design" packages/` 为空）
- [ ] 组件样式中无硬编码色值，且全部为 `<style scoped lang="less">`
- [ ] 无 `function` 声明（只用箭头函数）
- [ ] 产品代码无 JS 源文件（只有 `.ts` / `.vue`），`pnpm typecheck` 全绿
- [ ] 验收脚本或检查项写进仓库（`scripts/verify-*.mjs`），不靠人工记忆

## 明确不在 v0.1 范围

鉴权登录、菜单权限码、多语言、视觉回归基线、插件系统、主题可视化编辑器、浏览器内编译场景源码、SSR、云端托管、组件市场、与旧项目任何形式的代码共享。
