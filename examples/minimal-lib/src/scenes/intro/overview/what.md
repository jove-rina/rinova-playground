不需要注册路由、不需要写页面组件：在 `scenes/` 下放一个 `.vue` 或 `.md`，它就是一个场景。

这个站点是 `@rinova/playground` 的示例库（Minimal Lib）。左边每一组对应 `src/scenes/<分组>/` 下的一个目录，
每一项对应一个页面，页里的每个场景都是目录里的一个文件，内容就是你能看到的那块内容。

## 三个概念

- **分组**：目录名 → 侧栏显示名，顺序由 `playground.config.ts` 的 `groups` 声明决定。
- **页面**：一个目录，自带 `meta.ts` 声明标题、说明和绑定哪个组件；右上角的 API 表就是它的契约。
- **场景**：页面目录下的 `.vue` 或 `.md` 文件，文件内容就是这一块展示。Markdown 场景不展示源码。

::: tip 这一组为什么没有 API
介绍类页面不绑定组件，`meta.ts` 里不写 `component` 就没有 API 页签，只剩内容——
这和左侧 `Button` / `Card` 那些组件页是故意区分的。
:::

> 写文档、画对比表、列快捷键，都可以直接当一个 Markdown 场景来写，不用为它单独做一个页面。
