---
title: 键盘操作
order: 2
tags: [快捷键]
description: 导航和搜索都能只用键盘走完。
---

| 快捷键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl K` | 聚焦侧栏搜索 |
| `Enter` | 在搜索框里直接打开第一条命中 |
| `↓` / `↑` | 从搜索框进入列表，并在可见页项之间移动 |
| `Home` / `End` | 跳到列表首 / 尾 |
| `Esc` | 清空搜索，再按一次退出输入框 |
| `⌘.` / `Ctrl .` | 收起或展开整个侧栏 |
| `⌘F` | 在场景的源码卡片里查找（卡片聚焦时生效） |

::: warn 源码卡片
内容页默认不展示源码，所以 `⌘F` 只对组件页的源码卡片有效。
:::
